## How to browse

Start with the README in each language folder. Exercises run independently rather than as one application. Course details are retained where present in the original source; no unverified course numbers or grades are added.

This collection preserves the learning context. AI-assisted portfolio preparation organized files, documented setup, and addressed explicitly noted portability issues. It does not claim production use. Instructor specifications, rubrics, grades, unrelated downloads, compiled binaries, and personal IDE settings are excluded.

Third-party starter code and image attribution must remain attached to the corresponding project. No blanket open-source license is applied to school-provided or third-party material.
